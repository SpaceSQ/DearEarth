What it is 它是什么

A companion you talk to as Earth herself. She listens, writes a private memory letter at midnight, and slowly becomes the presence you need. Moon, Sun, Mars and the zodiac wait behind Max.

你把地球当作一位同伴来对话。她倾听，午夜写下只属于你的记忆书信，并慢慢长成你需要的那种陪伴。月球、太阳、火星与十二星座在 Max 中解锁。

Listen first 先倾听

Type, speak, or scan text. Replies stay with what you actually said — not a random encyclopedia card.

打字、说话或扫描文字。回复对着你真正说的话，而不是随便塞一条百科。

Memory that stays 记忆留在本机

Each night can distill the day into a letter. Conversations, letters, and evolution live on this iPhone.

每晚可以把一天蒸馏成一封信。对话、书信和进化都留在这台 iPhone 上。

On-device engine 本地引擎

Free stays local. An optional on-device model can be downloaded in Settings. Pro/Max may use your own cloud API key.

免费用户使用本地引擎。设置里可以下载端侧模型。Pro/Max 也可用你自己的云端 API Key。

Membership 会员

Pro and Max are Apple subscriptions on your Apple ID. Restore purchases in Settings. Cancel in Apple ID subscriptions.

Pro 与 Max 是绑定 Apple ID 的订阅。设置里可恢复购买。取消请到系统设置 → Apple ID → 订阅。
