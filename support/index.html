How to use the app 怎么用

  1. Open Dear Earth. There is no required account. Earth is ready to talk on the first launch.

    打开 Dear Earth。无需注册。第一次启动就可以和地球说话。

  2. Use the single input bar: type, hold the microphone, or scan text from the camera or a photo.

    底部只有一条输入栏：打字、按住话筒，或用相机 / 照片扫描文字。

  3. Chat is the default. Task mode is for Pro/Max while the engine is set to an AI model API. Free sees the Task switch greyed out.

    默认是普通聊天。任务模式需要 Pro/Max，并且引擎已切到 AI 大模型 API。免费用户的任务开关是灰色的。

  4. Memories: everyone can see today’s log and the list of letters. Opening a letter is Pro/Max.

    记忆：所有人都能看当天记录和书信列表。点开书信是 Pro/Max。

  5. Evolution: the overview is for everyone. Weekly, monthly, yearly breakdowns and the persona portrait are Pro/Max.

    进化：总览对所有人开放。周 / 月 / 年递变和人格画像是 Pro/Max。

  6. Settings → Language changes in-app words. The launch animation is English. Settings → Account has Log out, and Delete account & local data.

    设置 → 语言只改应用内文字。开屏动画是英文。设置 → 账号有登出，以及注销并删除本机数据。

  7. Membership is an Apple subscription. Restore purchases in Settings. Cancel in Settings → Apple ID → Subscriptions. The app cannot cancel it for you.

    会员是 Apple 订阅。设置里可恢复购买。取消请到系统设置 → Apple ID → 订阅。应用不能代为取消。

A path for review 审核可以这样走

  1. Launch Dear Earth. Watch the night-blue prelude, or tap Skip. Land on chat with Earth. No sign-in sheet.

    启动 Dear Earth。看完深空夜蓝开屏，或点 Skip。进入与地球的对话。没有登录表。

  2. Send “Good evening” or “晚上好”. The reply should meet the greeting, not an unrelated fact.

    发送 “Good evening” 或 “晚上好”。回复应接住问候，而不是一条无关百科。

  3. Open the sparkles control and tap Moon or another celestial. Free/Pro should see the Max upsell. Earth stays available.

    点右上角星标，再点月球或其他星体。免费 / Pro 应看到 Max 升级说明。地球始终可用。

  4. Open Memories, Evolution, and Settings. In Settings, read About, Privacy, Account (Log out / Delete local data), and Restore purchases.

    打开记忆、进化和设置。在设置里查看关于、隐私、账号（登出 / 注销本机数据）和恢复购买。

  5. Optional: Settings → Companion engine, download the on-device model on Wi-Fi. Optional: allow weather and calendar from the in-chat card or Settings. Denying permissions must not block chat.

    可选：设置 → Companion engine，在 Wi-Fi 下下载端侧模型。可选：在对话卡片或设置里允许天气与日历。拒绝权限不得挡住对话。

If something does not respond 没有反应时

  • Microphone freeze was fixed. If speech is denied, a message appears; enable Microphone and Speech Recognition in iOS Settings → Dear Earth, or type.

    话筒卡死已修复。若拒绝了语音权限，会看到提示；到系统设置 → Dear Earth 打开麦克风和语音识别，或直接打字。

  • Without a downloaded model, chat still uses the on-device companion. Memories show an install prompt instead of a fake letter.

    还没下载模型时，对话仍走本地陪伴。记忆页会提示安装，而不会写一封假书信。

  • Task mode on Free is disabled. On Pro/Max it asks you to switch the engine to AI Model API first.

    免费用户的任务模式不可用。Pro/Max 若仍是本地引擎，会先请你切到 AI 大模型 API。

  • Log out clears API keys and engine choice. Memories stay. Delete account & local data needs the red confirmation and wipes this iPhone only.

    登出只清 API Key 和引擎选择，记忆仍在。注销并删除本机数据需要红色确认，且只清这台 iPhone。

Permission purposes 权限用途

  • Microphone. Only while you hold the mic button, so you can speak instead of type.

    麦克风。 仅在你按住话筒时使用，方便用说的代替打字。

  • Speech recognition. Turns what you say into text on this iPhone.

    语音识别。 在本机把你说的话转成文字。

  • Camera / photos. Scan printed or handwritten text into the message. The image is not uploaded for chat.

    相机 / 相册。 把印刷或手写文字扫进消息。聊天不会把照片上传。

  • Location while in use. Approximate location only, so Earth can feel today’s weather. Location does not leave the device.

    使用期间的位置。 只用大概位置感受今天的天气。位置不离开本机。

  • Full calendar access. A glance at the 24 hours around now (a busy meeting, a free weekend, a trip tomorrow). Events stay on the device.

    日历完全访问。 看一眼此刻前后 24 小时（会前、周末空闲、明日出行）。日程留在本机。
